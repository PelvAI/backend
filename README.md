# 🌸 PelvIA Backend API

> **The next-generation FemTech platform for pelvic health.**

PelvIA is a specialized healthy aging and pelvic health assistant, designed to providing personalized clinical follow-up and progress tracking through an advanced scoring and recommendation engine.

---

## 🛠️ Tech Stack

- **Framework**: [FastAPI](https://fastapi.tiangolo.com/) (High-performance Python API)
- **Database**: [PostgreSQL](https://www.postgresql.org/) with [SQLAlchemy](https://www.sqlalchemy.org/) (Async support)
- **Migrations**: [Alembic](https://alembic.sqlalchemy.org/)
- **Validation**: [Pydantic v2](https://docs.pydantic.dev/)
- **Auth**: Firebase Admin SDK (Dev mode override supports simple testing)
